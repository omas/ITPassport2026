## ITパスポート試験概要

ITパスポート試験は，ITを利活用するすべての社会人・学生が備えておくべき。ITに関する基礎的な知識を証明する国家試験

- 試験時間: 120分
- 出題数: 小問 100問（四肢択一式）
- 出題形式: CBT方式（パソコンで解答）
- 受験手数料: 7,500円（税込）
- 受験資格: 制限なし（誰でも受験可能）

### 出題範囲

試験内容は、企業の経営からITの技術まで非常に幅広く、以下の3つの分野から出題されます。

- ストラテジ系： 35問程度(企業活動,法務,経営戦略,マーケティングなど)
- マネジメント系: 20問程度(プロジェクトマネジメント,システム開発の工程,サービスマネジメントなど)
- テクノロジ系: 45問程度(ネットワーク,セキュリティ,データベース,基礎理論など)

### 試験のメリットと難易度

- 国家資格のIT系試験なので，知名度や需要が高く学生のうちで取得すると高く評価される
- ITリテラシーの証明になるほか，ビジネスの全体像(経営・財務・法務)も体系的に学べる
- 国家試験としては比較的取得しやすいレベルだが，各項目の専門用語に慣れる必要がある
- 初学者が合格を目指す場合，おおよそ150 〜 180時間程度の学習が必要とされている

## 講座の目的

ITパスポート試験は，IT系国家資格の中では比較的やさしいと言われているものの，高校生の合格率は25%程度にとどまります。学校の予習・復習や部活動などで忙しい学生にとって，合格に必要な150〜180時間の学習時間を確保することは容易ではありません。
そこで本書（本講座）では，最重要用語の解説とAIを活用した学習法を組み合わせ，短期間でのITパスポート試験合格を目指します。
