## ITパスポート試験に出てくる用語を効率的に記憶する

あらゆる試験において記憶することが重要であることは論を待たないが，特にITパスポート試験では高校生にとって馴染みのない用語がたくさん出てくる。初めてみる言葉はだれにとっても難しく感じられる。
効果的に記憶するために記憶のメカニズムと効果的な記憶法を解説する

### 記憶のメカニズム

記憶には，即時記憶，近時記憶，長期記憶があります。 例えば，電話番号などの数字を数秒間覚えるようなきわめて短時間の記憶を即時記憶といいます。通常ではこのような電話番号はすぐに忘れてしまいますが，これが大切な相手の番号となると覚えておこうとします。その場合，脳は情報信号の処理と符号化を行います，これが近時記憶です。

関連付けの強さにより，数秒から数日，長いものだと1〜2年情報が留まる場合もあるそうです。この情報が海馬(脳のある分野)の中にとどまっている間に蓄積されているほかの記憶情報と関連づけられると，新しい記憶として脳内に蓄積されると長期記憶となります。

従来の記憶方法は，記憶強化(反復)が有効と考えられていましたが近年の研究によると単なる繰り返し(維持リハーサルとよばれる)は，長期記憶にそれほど有効ではないと結論付けられています。代わって情報に対するイメージの構成や意味的処理によって既有知識と関連づける 精緻化リハーサルが有効であることがわかって来ました。

記憶したいものをカテゴリーに分類したり，記憶すべき項目をあらかじめ決めた場所に置いたり，各単語や単語リストのイメージ化などがそれにあたります。但し，この方法は，難易度が高かったり、手間がかかることが多いです。

簡単で効果的な，記憶プロセスにこのようなものがあります。

#### 効果的な記憶法 その1 (delayed method)

- delayed repetition 聞く → 言う (時間差復唱)
- delayed dictation 聞く → 書く (時間差ディクテーション)
- delayed copying 読む → 書く (遅延写経)
- Read & look-up 読む → 言う (時間差音読)

例えば，以下を試してみましょう。

1. 誰かに読み上げてもらった単語を，すぐに復唱する
2. 誰かに読み上げてもらった単語を，15秒間待ってから，復唱する

2のやり方が圧倒的に記憶されることが体験できるでしょう。

#### 効果的な記憶法 その2 (Spaced rehearsal)

一度に覚えるのと，分けて覚えるのでは，分けて覚えるほうが効果が高くしかも長く続く続き，そして同じく学習を分散するにしても，その間隔を次第に広げる方が効果があることが知られています。

たとえば，定期的に復習するよりは，1日後，1週間，1月後……という間隔で復習する方が定着度が高くなります。次第に間隔を広げていくこのやり方が Spaced rehearsal とよばれます。

Spaced rehearsalを活用した1時間の勉強予定はたとえばこうなります。

30分 新規項目の学習
05分 定着のための小休憩と復習の準備
05分 1日前の学習項目の復習
05分 1週間前の学習項目の復習
05分 1ヶ月前の学習項目の復習
10分 今日の学習項目の復習

学習計画を，カレンダーなどで管理することが，重要になります。スマートフォンをもっているなら Ankiなどのソフトをつかってもよいです。 新規学習6割，復習4割の割合でおこなうこと良いでしょう。

#### take note

受験に必要なのは長期記憶，そのメカニズムを理解しましょう
近時記憶には，複合動作(声に出す，書く)やdelay Methodが有効
長期記憶に転換するためには，関連付けや，繰り返し方が重要

## ITパスポート試験における重要キーワードを学習するためのprompt 

```prompt
[前提条件] あなたはITパスポート試験の講師です。 一番下の【解説してほしいIT用語】について、以下の[出力フォーマット] 従って分かりやすく解説してください。
専門用語などは使わないでください，装飾も必要ないです
フォーマットの最後にITパスポート試験での出題傾向を追加してください

[出力フォーマット]

- 核心部分を具体例で (なぜその技術が生まれたのかを解説します。実際のサービス名などを交えて4行から5行でわかりやすく解説してください)
- キーワード (ITパスポート試験において、この用語とよく一緒に出るキーワードを提示してください。どのような文脈で問われるのかを解説してください)
- 類似用語との違い（ひっかけ問題の対策にこの用語と混同しやすい関連用語やダミー用語を必ず挙げてください。それぞれの決定的な違いや提供範囲などを比較してください。初心者が陥りやすい罠を未然に防ぐための解説をします)
- ITパスポート試験での出題傾向(過去問を使いこの用語がどう問われるかを解説します。特有のひっかけや重要度などを2行から3行で提示してください)

[解説してほしいIT用語]：DX

```
