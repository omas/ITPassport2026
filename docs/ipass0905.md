# 第五回 ITパスポート講座 in IT College Okinawa

Tパスポート試験の「テクノロジ系」とは、ITを「作る側・使う側」の基盤となるIT技術の知識を問う出題分野のことです。 

ITパスポート試験を構成する3分野の中で最大ボリュームの約45%（100問中45問程度）を占めており、合否に最も直結する重要な分野として位置づけられています。
ネットワークとセキュリティの問題の出題割合が高いのでまずはこの2分野を重点的に学習することが効率的です。
